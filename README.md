# David Assistive Communication

My uncle was a quadroplegic who eventually died of pneumonia after a year of being unable to recover in the hospital due to a collapsed lung.

This project was created in an effor to give my uncle easier ways to continue to communicate with family who had difficulty understanding his weak voice.

The first page is a LEAP Motion keyboard, the idea being that my uncle would hover his hand over the leap motion and try to move in 3D space and press down on a virtual scaled up keyboard. This never ended up getting completed and was too inaccurate.

https://proloser.github.io/david/

Afterwards, I learned my family was using morse code to communicate with my uncle, but it was slow and difficulty.

In response, I built a second test page intended to be used on a phone or tablet. The idea is the user taps on the red box using morse code (with adjustable timing settings at the bottom of the page). As the user uses morse code to form words and sentences, the webpage dictates the letters, words and sentence while it's being built.
